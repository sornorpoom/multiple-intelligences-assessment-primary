## 🌟 คุณสมบัติเด่นของระบบ (Features)

1. **แบบประเมินครอบคลุม 9 ด้านพหุปัญญา 45 ข้อคำถาม (ปรับภาษาและสถานการณ์สำหรับ ป.4-ป.6):**
   - ด้านภาษา (Linguistic Intelligence)
   - ด้านตรรกะคณิตศาสตร์ (Logical-Mathematical Intelligence)
   - ด้านมิติสัมพันธ์ (Visual-Spatial Intelligence)
   - ด้านดนตรี (Musical Intelligence)
   - ด้านรอบรู้ธรรมชาติ (Naturalist Intelligence)
   - ด้านร่างกายและการเคลื่อนไหว (Bodily-Kinesthetic Intelligence)
   - ด้านการเข้าใจผู้อื่น (Interpersonal Intelligence)
   - ด้านการเข้าใจตนเอง (Intrapersonal Intelligence)
   - ด้านการดำรงอยู่ของชีวิต (Existential Intelligence)

2. **ความยืดหยุ่นในการจัดสอบ:**
   - ทำแบบประเมินรวดเดียว 45 ข้อ
   - หรือแบ่งทำเป็น 3 ชุดย่อย (ชุดละ 15 ข้อ) ตามความเหมาะสมของนักเรียน

3. **ระบบคำนวณและประมวลผลคะแนนตามผังข้อสอบ (Test Blueprint):**
   - คำนวณคะแนนดิบรายด้าน (เต็ม 10 คะแนน) และแปลงเป็นร้อยละ (0–100%)
   - จำแนกระดับพัฒนาการ 5 ระดับ (ระดับ 0 ถึง ระดับ 4)
   - ตรวจจับเงื่อนไขข้อมูลไม่เพียงพอ (ระดับ 0) โดยอัตโนมัติ

4. **การแสดงผลเชิงภาพและกราฟิกวิเคราะห์ (Visual Analytics):**
   - **Radar Chart (กราฟใยแมงมุม):** แสดงสมดุลพหุปัญญาทั้ง 9 มิติ
   - **Bar Chart (กราฟแท่ง):** เปรียบเทียบคะแนนร้อยละและระดับความสามารถ
   - **3 อันดับจุดเด่น (Top 3 Strengths):** สรุปด้านที่โดดเด่นพร้อมคำแนะนำในการส่งเสริมศักยภาพสำหรับเด็กวัยประถมปลาย

5. **ระบบส่งออกรายงานผลเป็น PDF (PDF Export):**
   - จัดรูปแบบรายงานขนาด A4 สวยงาม เหมาะสำหรับการรายงานผลให้นักเรียน ครูประจำชั้น และผู้ปกครอง

6. **ระบบ Client-Side 100%:**
   - ใช้งานผ่านเบราว์เซอร์ได้ทันทีโดยไม่ต้องเชื่อมต่อฐานข้อมูล
   - มีปุ่ม "ดูตัวอย่างผลลัพธ์" (Demo Data) ให้ทดสอบระบบได้ทันที

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
ประถมปลาย/
├── index.html                  # หน้าเว็บหลักของระบบ (Single Page Application)
├── css/
│   └── styles.css              # สไตล์เฉพาะ แอนิเมชัน และ Print Stylesheet
├── js/
│   ├── questions-data.js       # ฐานข้อมูลข้อสอบ 45 ข้อและเกณฑ์การให้คะแนน (ป.4-ป.6)

│   ├── charts.js               # โมดูลสร้าง Radar Chart และ Bar Chart ด้วย Chart.js
│   ├── pdf-export.js           # โมดูลสร้างและดาวน์โหลดรายงาน PDF

├── พหุปัญญา ประถมปลาย.pdf        # เอกสารอ้างอิงของสภาการศึกษา
└── README.md                   # คู่มือและรายละเอียดโครงการ
```

## 📊 เกณฑ์การแปลผลระดับพหุปัญญา

| คะแนนร้อยละ (%) | ระดับพหุปัญญา | คำอธิบายระดับความสามารถ |
| :---: | :---: | :--- |
| ตอบตัวเลือก 5 $\ge$ 2 ข้อ | **ระดับ 0** | **ข้อมูลไม่เพียงพอ:** ยังไม่ได้สำรวจความชอบ/ความสนใจ |
| **0 – 29%** | **ระดับ 1** | **รวบรวมสารสนเทศ:** เริ่มสำรวจความถนัดผ่านการลองทำกิจกรรม |
| **30 – 75%** | **ระดับ 2** | **สร้างความเข้าใจ:** เริ่มชัดเจนในความชอบและสิ่งที่ทำได้ |
| **76 – 83%** | **ระดับ 3** | **คิดบังเกิดผล:** รู้ชัดเจนและทำจนเกิดผลงานที่มีคุณภาพ |
| **84 – 100%** | **ระดับ 4** | **คิดเชิงกลยุทธ์และคิดสะท้อนกลับ:** แก้ปัญหาซับซ้อนและขยายศักยภาพ |
